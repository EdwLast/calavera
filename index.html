Toca una vez para despertarla

El navegador exige un toque para habilitar el sonido. Después de esto la calavera funciona sola, sin volver a tocar la pantalla.

Para que arranque sin ningún toque, ábrela en un navegador kiosco con reproducción automática habilitada, o dentro de un WebView propio.

Ajustes

Cerebro (LLM)

Con Gemini, si el respaldo queda vacío se usa «gemini-3.5-flash-lite». Si ese nombre no existe en tu cuenta, pon otro modelo de AI Studio.

Voz (TTS)

Gemini: voz «Algenib» (ronca) o «Gacrux» (madura), modelo «gemini-3.8-flash-tts»; si dejas la key vacía usa la del cerebro. OpenAI: voz «onyx». ElevenLabs: pega el Voice ID de una voz grave, modelo «eleven_multilingual_v2».

Efectos

Tono más bajo = voz más grave y lenta. El reverb solo se aplica con OpenAI o ElevenLabs.

Holograma

Con el plástico a 45° la imagen se ve invertida: activa «Espejar» y, si la calavera aparece acostada o cabeza abajo, prueba con «Girar». Para fijar la orientación horizontal, abre la calavera desde el ícono instalado.

Comportamiento

Mientras este panel está abierto, la calavera no escucha. Las claves se guardan solo en este navegador.
